## 🚀 About Me

I’m a Web Developer focused on building modern, responsive, and user-friendly web applications. I work with React.js, JavaScript, HTML5, CSS3, Tailwind CSS, Node.js, Express.js, MongoDB, and REST APIs.

I enjoy turning ideas into functional web applications and working on both frontend and backend development. Recently, I’ve been building **Cartora**, a full-stack e-commerce marketplace with Customer, Seller, and Admin roles, product management, seller management, authentication, cart functionality, and backend authorization.

I also built **TidyNote**, a MERN-based notes application with authentication, protected routes, CRUD operations, search, favourites, trash management, and a rich text editor.

I’m continuously improving my development skills through real-world projects and looking for opportunities to contribute to meaningful web development projects.

You can reach me at **ramishajamshaid7@gmail.com**.
